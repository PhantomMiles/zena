# @zena/contracts

## What it does

Solidity smart contracts for the Hyperledger Besu consortium chain, plus TypeScript type bindings generated by the compile step. Contract groups (Phase 1–3):

| Contract        | Purpose                                                             |
| --------------- | ------------------------------------------------------------------- |
| `EventRegistry` | EPCIS 2.0-style signed event log                                    |
| `Handover`      | Dual-signed custody transfer between two member nodes               |
| `Settlement`    | Conditional payout trigger once contract terms and POD are verified |
| `Governance`    | Membership, validator rotation, upgrade proposals and votes         |

## Why it is designed this way

ABI types live here as the single source of truth. `@zena/sdk` and `@zena/node` both import from this package, so any ABI change is visible immediately at build time across the monorepo. All contracts require an independent audit before any real payment flows (rule 20).

## Test

```bash
pnpm --filter @zena/contracts test
```

Solidity unit tests (Hardhat/Foundry) and fuzz tests are added in Phase 1 when contracts are written.
